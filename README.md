# 🌿 EcoTrack - Calculadora de Huella de Carbono

## 📄 Descripción
EcoTrack es un prototipo web interactivo desarrollado mediante la metodología **Vibe Coding** utilizando Cursor. Permite calcular la huella de carbono personal semanal basada en hábitos de transporte, energía y alimentación.

## 🛠️ Stack Tecnológico
- HTML5
- CSS3 (Variables, Flexbox/Grid, tema ecologista)
- JavaScript ES6 (Lógica local de emisión)

## 🎯 Reglas de Orquestación (.cursorrules)
El desarrollo estuvo guiado por el archivo `.cursorrules` priorizando la simplicidad, arquitectura limpia sin dependencias complejas y despliegue rápido.
